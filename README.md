# Aura Health Medical Center — Demo Website

A responsive hospital website made with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.
3. Internet access is required for the Google Fonts and Unsplash demo photos.

## Before publishing
- Replace fictional hospital details, staff names, phone number, address, timings and illustrative statistics with verified information.
- Replace the `.example` email address.
- The appointment form is front-end only: it validates inputs but does not send, save, or book appointments. Connect it to a secure backend or a trusted booking provider before launch.
- Add an appropriate privacy notice and secure handling of patient information before collecting real data.
- Verify image licences and usage terms for your production deployment.
